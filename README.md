## 🌍 The Problem

Hospitals operate across dozens of disconnected software silos. When patient data travels between modules, critical gaps emerge:
- **$42 Billion/year** global cost of medication errors (WHO).
- **40% of medication errors** occur at module boundaries (e.g., patient discharged from ward, but pharmacy never notified; wrong drug dispensed to next occupant).
- **78% of hospitals** cannot explain why their clinical AI flagged a patient — now **illegal under EU AI Act Article 50** (enforced August 2, 2026).
- **NABH Accreditation in India** requires strict Root Cause Analysis (RCA) and auditability for clinical AI under standard **QPS.5**.

Manual audits take **2 to 3 weeks** and cost thousands of dollars. **MedTrace + IBM Bob accomplishes it in 90 seconds.**

## 🚀 Key Modules in MedTrace

### 1. 🗺️ NexusGuard (Patient Journey Data Flow Map)
- Visualizes directed data flows between all hospital modules (Admission, Wards, Pharmacy, Lab, Billing, MediSentinel™ AI, EHR).
- Automatically pinpoints broken links (`gap` edges in red) where medication and billing discrepancies occur.
- Provides one-click automated code fixes proposal generated by IBM Bob.

### 2. 📋 ClinicalPassport (AI Decision Audit Trail)
- Generates cryptographic, timestamped, human-readable audit passports for clinical AI triage decisions.
- Integrates model decomposition (BiLSTM trend analysis, XGBoost lab features, ClinicalBERT note semantics).
- Provides exact **SHAP value attribution** (e.g., SpO₂ +0.41, Heart Rate +0.34, BP +0.25).
- Captures clinical supervisor sign-off (`Dr. Sharma · Clinical Lead`) for Human-In-The-Loop (HITL) compliance.

### 3. 🤖 IBM Bob Live Session
- Interactive conversational workspace demonstrating IBM Bob's three native modalities:
  - **Ask Mode**: Codebase exploration across 270k context.
  - **Plan Mode**: Risk ranking, clinical exposure classification, and remediation strategy.
  - **Agent Mode**: Autonomous test generation, PR drafting, and schema bridging.

### 4. ⚖️ CompliancePanel (Regulatory Defensibility Package)
- Real-time audit readiness scoring across three simultaneous legal standards:
  - **EU AI Act Article 50**: High-risk AI transparency and post-market tracking.
  - **NABH 5th Edition QPS.5**: Quality, Patient Safety, and Sentinel Event management.
  - **India DPDP Act 2023**: PHI scrubbing, anonymization, and strict purpose limitation.
- One-click exportable **Regulatory Audit Dossier (JSON/PDF)** for hospital accreditation boards and court defense.
- Interactive "Simulate Regulatory Audit" inspector demonstrating live legal defensibility.

## 🏁 Quick Start

### 1. Installation
```bash
cd medtrace
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
